# Классификация данных по стандартам ISO/IEC 27001/27002

**Секретные данные (Secret)**
Описание: Данные, утечка которых может нанести катастрофический ущерб компании (юридический, финансовый, репутационный), привести к потере конкурентного преимущества или прекращению деятельности.

*Данные PropDevelopment:*

- Ключи и сертификаты для шифрования/подписи (включая интеграцию с госорганами)
- Исходный код критически важных систем (алгоритм онлайн-сделки)
- Конфигурационные файлы инфраструктуры с паролями и секретами
- Мастер-ключи систем шифрования баз данных

**Конфиденциальные данные (Confidential)**
Описание: Персональные данные и данные, защищаемые законодательством (152-ФЗ), а также ключевые бизнес-данные, утечка которых нанесет серьезный ущерб.

*Данные PropDevelopment:*

- Персональные данные клиентов/собственников: ФИО, паспортные данные, ИНН, контакты (телефон, email)
- Данные о сделках и финансовые реквизиты
- Биометрия (если используется в "Умном доме")
- Данные онлайн-сделки: юридические документы, подписи, данные интеграции с госреестрами
- Финансовые данные: полная бухгалтерская и управленческая отчетность, детали платежей
- Ключевые бизнес-модели и прогнозы из BI-систем

**Внутренние данные (Internal)**
Описание: Данные для служебного пользования, не предназначенные для публикации. Их утечка может нанести умеренный ущерб, раскрыть внутренние процессы.

*Данные PropDevelopment:*

- Внутренние регламенты, политики, архитектурные схемы
- Данные о текущих ремонтах, планировках, спецификациях инженерных систем ЖК
- Внутренняя переписка и аналитика
- Логи и метрики систем (без персональных данных)
- Данные о производительности и нагрузке на сервисы

**Публичные данные (Public)**
Описание: Данные, предназначенные для широкой аудитории. Их искажение или потеря ведет к незначительному или репутационному ущербу.

*Данные PropDevelopment:*

- Каталог недвижимости на витрине (фотографии, планировки, цены, общие характеристики)
- Публичные новости и объявления от управляющей компании в приложении для собственников
- Общая информация о компании на сайте
- Открытые API-документации для партнеров (без ключей доступа)
