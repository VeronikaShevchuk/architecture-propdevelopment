| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| cluster-admin | Полные права на весь кластер: Полный доступ ко всем ресурсам во всех namespace; Создание/удаление/изменение любых ресурсов; Доступ к Secrets, ConfigMaps, Nodes; Управление RBAC | Команда DevOps/Администраторы кластера; Главный специалист по ИБ |
| security-auditor | Права на аудит и мониторинг:Чтение всех ресурсов (get, list, watch); Доступ к логам и событиям; Чтение Secrets (только для удита); Чтение RBAC правил |Специалист по ИБ; Аудиторы безопасности;Команда Compliance |
| namespace-admin | Полные права в конкретных namespace: Полный доступ ко всем ресурсам в назначенных namespace; Создание/удаление/изменение ресурсов; Доступ к Secrets в рамках namespace |Лидеры продуктовых команд; Senior разработчики ответственных доменов |
| developer | Права разработчика в namespace: Создание/изменение Deployments, Services, ConfigMaps; Чтение Pods, Logs, Events; НЕТ доступа к Secrets; НЕТ доступа к Nodes, PersistentVolumes | Разработчики функциональных команд; QA инженеры |
| viewer |Только чтение в namespace: Просмотр (get, list, watch) ресурсов; Чтение логов и событий; НЕТ доступа к Secrets, ConfigMaps; НЕТ возможности изменять что-либо | Бизнес-аналитики Менеджеры проектов; Технические писатели |
| ci-cd-bot |Права для CI/CD системы: Обновление Deployments в конкретных namespace; Создание Jobs, CronJobs; Чтение статуса Pods; Ограниченный доступ | Jenkins/GitLab CI сервисные аккаунты GitHub Actions |
| tenant-admin |Администратор сервисов ЖКУ (специальная роль):Полный доступ в namespace "tenant-services"; Ограниченный доступ к Secrets (только ЖКУ); Мониторинг ресурсов потребления | Администраторы сервисов ЖКУ; Менеджеры Управляющей компании |
| smart-home-operator |Оператор сервисов "Умный дом": Доступ к namespace "smart-home"; Чтение/запись ConfigMaps; Рестарт Pods; Мониторинг логов | Инженеры поддержки Умного дома; Операторы IoT устройств |
